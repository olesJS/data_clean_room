**Опорні числа** (перераховано з файлів; дати порівнюються з поточною датою, дефектні дати лежать у 2027–2028 рр.):

| | Нульові та від'ємні `amount_uah` | 8 (4 + 4) |

| | Quality Score з правилами `customers_rules.yaml` | 130 з 1000 → **87,0** |

**Формула Quality Score** (ухвалена, SCRUM-40): Score = 100 × (N − N_пр) / N, де N кількість рядків, N_пр кількість різних рядків з хоча б одним порушенням правила з дією reject або flag або повних копій іншого рядка (друге й наступні входження). Один знак після коми. Дія block оцінку не змінює, а блокує публікацію. Статистичні викиди без окремого правила на оцінку не впливають.

### TC-04.5 Підтвердження і виправлення класифікації (основний сценарій, AC1) · P1 · авто + вручну · ⚠
